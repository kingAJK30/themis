# Themis
A curated Linux desktop inspired by Omarchy, built in NixOS around sensible defaults and user freedom.
 test
## Philosophy
Themis is built around the idea of order without rigidity.

It aims to provide a thoughtfully curated computing experience through sensible defaults that work out of the box, without restricting the user's ability to make it their own.

Our principles:
- **Sensible Defaults:** Everything should work well out of the box. Users shouldn't have to assemble their own experience.
- **Freedom of Choice:** Defaults are recommendations, not requirements. Customization should be straightforward and encouraged.
- **Thoughtful Curation:** Every inclusion should have a purpose. Avoid unnecessary complexity and trend-driven features.
- **Consistency:** Components should work together as a cohesive experience.
- **Maintainability:** Prefer reliable, stable solutions over novelty.

Themis should make computing easier, not dictate how people should compute.
